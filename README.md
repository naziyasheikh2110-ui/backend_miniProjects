# Quora Post CRUD Application

. This project focuses on backend fundamentals, RESTful routing, and clean project structure while implementing full **CRUD functionality**.

---

## 🚀 Features

* Create a new post
* View all posts
* View a single post in detail
* Edit an existing post
* Delete a post
* Server-side rendering using **EJS**

---

## 🛠 Tech Stack

* **Node.js**
* **Express.js**
* **EJS (Embedded JavaScript Templates)**
* **HTML & CSS**
* **RESTful Routing**

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/naziyasheikh2110-ui/backend_miniProjects.git
```

2. Navigate to the project directory:

```bash
cd backend_miniProjects
```

3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
node index.js
```

5. Open your browser and visit:

```
http://localhost:8080
```
